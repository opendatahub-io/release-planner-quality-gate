# Release Planner Quality Gate

Release Quality Gate 1: Feature Definition of Ready for Planning. Validates RHAISTRAT features
have RICE scores and priority set before they are considered ready for release planning.

## Architecture

"Agents analyze, scripts decide" — Python orchestrator handles deterministic logic (JQL, field
checks, verdicts, labels). Claude Code skill handles RICE score generation when missing.

## Execution Modes

```bash
# Single issue (testing)
python scripts/quality_gate.py --issue RHAISTRAT-1745
python scripts/quality_gate.py --issue RHAISTRAT-1745 --dry-run

# Batch (pipeline)
python scripts/quality_gate.py
python scripts/quality_gate.py --dry-run
```

`--dry-run`: Claude generates RICE recommendations locally, but NOTHING is written to Jira
(no fields, no comments, no labels). Full run writes RICE + gate labels.

## Jira Integration

Uses `scripts/jira_utils.py` (copied from strat-creator). Requires env vars:
- `JIRA_SERVER` — e.g. https://redhat.atlassian.net
- `JIRA_USER` — Jira email
- `JIRA_TOKEN` — API token

## RICE Custom Fields

| Field | ID | Type |
|-------|-----|------|
| Reach | customfield_10862 | number (1,3,5,8,13) |
| Impact | customfield_10836 | number (1,3,5,8,13) |
| Confidence | customfield_10838 | dropdown (option IDs: 16144=100%, 16145=75%, 16146=50%) |
| Effort | customfield_10637 | number (1,2,3,5,8,13) |
| RICE Score | customfield_10864 | auto-calculated, never set manually |

## Labels

| Label | Meaning |
|-------|---------|
| `rp-qg1-pass` | Passed Gate 1 (has RICE + priority + human-sign-off) |
| `rp-qg1-fail` | Failed Gate 1 |
| `rp-qg1-auto-rice` | RICE was auto-generated by Claude |

## Testing

Run `make test` after every code change. Use `make test-unit` for script-only changes,
`make test-integration` for Jira-touching changes (uses jira-emulator).
